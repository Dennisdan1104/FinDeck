# @deepseek-ai/dsh-client-ui-settings-skills

[English](README.md) | 中文

## 概述

`dsh-client-ui-settings-skills` 是 dsh Web 客户端的技能设置页面，基于 Host 的 `skillsAdmin` Remote 命名空间组织为四个标签页。**已安装**列出当前部署可提供的全部技能，提供启用开关、可创建/编辑/查看/删除用户技能的内联编辑器，以及手动重新扫描。**精选库**一键安装精选的开源技能。**迁移导入**把在其他 Agent 技能根目录（Claude Code、Codex）中发现的技能——或用户输入的绝对路径——复制进用户技能根目录。**从会话创建**把存储的会话按项目分组供勾选，并把选中的会话蒸馏为新技能：Host 提取转录文本，页面把种子提示词交给一个由 Host 技能创作工作模式组装的全新 AI 会话。所有写入都经由 Host 完成并先生效再应答——本页面不直接改文件，也不要求重启。

<a id="使用本包"></a>
## 使用本包

从设置导航打开**技能**，选择标签页。

**已安装**（默认页）每个技能一行，展示描述与元数据：来源桶（`custom`、`user-dsh`、`user-agents`、`bundled`、`project-dsh`……）、拥有正文的提供方、相对资源的解析目录，以及以「模型」/「用户」标签表示的调用策略。开关会把技能同时从所有消费者处隐藏——模型目录、`/` 菜单与按名加载——且禁用列表写入用户设置文档，重启后仍然生效。**重新扫描**重新执行提供方发现。**查看/编辑**在行上方的内联编辑器中打开技能文档；用户根目录之外的技能以只读方式打开并附说明。**删除**只对用户技能出现，并需要内联二次确认。**新建技能**打开同一编辑器；名称是 kebab-case 标识，创建后不可更改。

**精选库**列出精选开源技能及其出处、许可证与仓库链接。**安装**在主机端把 SKILL.md 下载到用户技能根目录，技能即刻生效，无需重启。已安装的条目会带标记且按钮禁用。

**迁移导入**按根目录分组展示在其他 Agent 技能根目录中发现的技能，单击即可导入到用户技能根目录；清单中已存在同名技能时不可导入。自定义路径行可导入任意绝对路径——包含 SKILL.md 的目录或单个 Markdown 文件。

**从会话创建**列出最近的会话（最新在前，最多 50 条），按项目折叠成可展开的分组——每个记录在案的工作目录一组，以路径最后一段为标签，Host 未记录目录的会话收进末尾一组——选择计数与**创建技能**位于选择器上方。选中一个或多个后点击**创建技能**，Host 会提取这些会话的转录文本，随后页面打开一个由 Host 的技能创作工作模式组装的新会话，其首条提示词就是提取种子：新会话的 AI 读取转录、向你提问澄清，然后写出 SKILL.md。同一个选择器也是该流程的另一个入口：在会话的模式控件里选择**技能创作模式**会把它作为全框对话框打开，确认后创建的就是那个新会话，而不是切换你正在读的会话。

当设置文档只读，或浏览器远到其设置仅进程内有效时，所有开关与写按钮都会禁用，页面也会说明。

<a id="理解实现"></a>
## 理解实现

<details>
<summary>实现细节——点击展开</summary>

页面自身不持有任何事实。每个变更 Remote（`setDisabled`、`create`、`update`、`remove`、`importExternal`、`installGallery`）都在自己的变更之后应答完整清单，因此一次被接受的应答会整体替换 store 中的条目，行永远不会显示只应用了一半的写入。被取代的应答由代际计数器丢弃。惰性加载的各个切片——精选库条目、外部根目录、forge 会话、编辑器已加载的文档——各自拥有独立的状态字段与代际计数器，一个标签页的慢应答永远不会覆盖另一个的。

可写性是清单无法携带的唯一事实，因此插件通过 `ctx.settingsScope` 绑定同一个 `skills` 设置命名空间，把其快照中的 `writable` 标志镜像进页面 store。单技能的可写性随编辑器的 `read` 应答到达；行上只有对应可写根目录的 `user-dsh` / `user-agents` 来源桶才提供删除。

forge 流程复用资产页的 AI 交接模式：`skillsAdmin.forge()` 应答种子提示词与它指定的技能创作预设，store 通过 `ctx.sessions` 创建由该预设组装的全新会话并打开它（外壳随之导航到会话页），然后把种子作为该会话的首条提示词提交。选择器在本地按 Host 行自带的 `cwd` 分组；页面不新增任何会话事实。同一个选择器组件服务两个框架——页内标签页与 `shell.overlay` 对话框——插件还提供 `skillForge` 服务（`openFor`）供输入框的模式选择询问：被认领的选择打开对话框、不切换任何会话，于是模式 id 的路由留在这里，而会话实际由哪个预设组装仍是 Host 的答案。

</details>

<a id="模型体验"></a>
## 模型体验

间接：本页的模型可见效果是它写入的禁用列表，以及它创建、安装或导入的技能。被抑制的技能会离开模型目录并拒绝按名加载，下一次组装的提示词不再宣传它；新增或修改的技能在 Host 重新扫描后的下一次目录读取时出现。forge 流程的种子提示词本身就是模型输入，作为它所创建会话的首条提示词提交。

#### KV 缓存影响

无直接影响；提示词只随其重建所依赖的目录变化，与提供方发现变化时完全相同。

## 已知限制与暂缓事项

<a id="已知限制与暂缓事项"></a>

- **不再被任何提供方发现的技能没有行。** 禁用列表仍保留其名，但页面只能渲染当前清单返回的技能；重新启用需要一次能再次发现该名称的发现。
- **禁用列表以名称为键、与层无关。** 两个层贡献同名技能时是同一个开关，与注册表的过滤一致。
- **行级删除的可见性由来源桶推导。** 清单行不携带可写标志，因此删除只对支撑 Host 可写根目录的 `user-dsh` / `user-agents` 桶出现；编辑器加载的文档才是编辑的权威判定。

<a id="开发说明"></a>
### 开发说明

<details>
<summary>维护者工作上下文——点击展开</summary>

本插件在 cordis `inject` 中声明 `sessions`、`remote.skillsAdmin` 与 `remote.sessionsAdmin`，并在信息性的 `dsh.client.inject` 边中列出 `@deepseek-ai/dsh-api-session-controller`（与 ui-assets 一致）。

</details>

**运行时不变量：** 不发布伴生不变量。本插件是仅导航条目的 section 插件，只读取 Remote 命名空间与一个设置作用域，不拥有跨插件的可变关系。
